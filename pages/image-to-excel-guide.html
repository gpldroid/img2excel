Step-by-step guide

How to Convert an Image to Excel

Use this workflow to extract a table from an image, check the recognized values, and export an editable XLSX file.

1. Prepare a clear source image

Use a sharp, well-lit image with the complete table visible. Keep the camera parallel to the page where possible, avoid glare, and make sure text is large enough to read. Common image formats such as JPG and PNG are suitable starting points.

2. Upload an image or use the camera

Open the ProTools converter and select an image from your device. On a supported device and browser, you can also use the camera capture option. Grant camera permission only when you intend to capture an image.

3. Adjust the image

Correct rotation and alignment, then use brightness, contrast, or grayscale controls if they make the text easier to distinguish from the background. Avoid excessive adjustments that erase thin characters or table borders.

4. Select the OCR language

In the OCR Languages control, select up to three language packs that match the text in the image. The catalog includes English, Russian, Arabic, and many other Tesseract-supported languages. For mixed-language documents, select each relevant language and review cells carefully, especially where writing direction changes within a row.

5. Run OCR and review the table

Start recognition and wait for the extracted table to appear. Check column boundaries, merged cells, punctuation, decimal separators, dates, and numbers. Edit incorrect cells directly, and add or remove rows and columns as needed.

6. Copy or export your data

Use the copy action to paste tab-separated data into a spreadsheet application, or export an XLSX workbook when you need a file. Reopen the exported workbook and inspect the values and column layout before sharing it.

Supported workflow and limitations

The current tool is designed for image-to-table extraction and XLSX export. OCR quality varies with source image quality, font, language, and table complexity. It is not a general-purpose PDF or Word converter, and it cannot reliably reconstruct every complex merged-cell layout.

Frequently asked questions

Does ProTools upload my image to a server?

The Tesseract OCR workflow runs in your browser and does not require uploading the selected image to a ProTools OCR server. Browser libraries and language data may be downloaded from external CDNs.

Can I extract tables in languages other than English?

Yes. Choose the matching language packs from the OCR Languages selector. The catalog includes English, Russian, Arabic, and many other languages supported by Tesseract. Select up to three languages for one scan. For Arabic and other right-to-left scripts, verify the resulting column order and cell contents.

Can I extract Arabic tables?

Yes. Select Arabic as the OCR language, then review reading order and cell alignment carefully because right-to-left text can be arranged differently from English tables.

Can I edit the extracted spreadsheet before export?

Yes. Review and edit cells in the on-page table, including adding or deleting rows and columns, before exporting the XLSX file.

Why are some values recognized incorrectly?

Blur, low resolution, shadows, skew, unusual fonts, and dense table borders can reduce recognition quality. See the OCR accuracy guide for practical improvements.
