Merge PDF

Combine multiple PDF documents into a single PDF.

Use the Merge PDF

Ready. Files are processed locally in your browser.

How to use Merge PDF

Select two or more PDFs, arrange them in the intended order, and merge them into one document. Download the combined PDF when processing finishes.

Supported workflow and limitations

The browser must be able to read each PDF. Encrypted or damaged files may fail. Interactive forms, bookmarks and document-level metadata may not be retained in the merged output.

Privacy and file handling

Your selected files are processed in your browser. ProTools does not require you to upload them to a document-processing server. Required JavaScript libraries and language data may be downloaded from their respective CDNs. Analytics and advertising are controlled separately by your cookie preferences.

Frequently asked questions

Can I change the file order?

Yes. The selected files are merged in the order shown in the file list; use the move controls before merging.

Are the original PDFs modified?

No. The tool reads the selected files and creates a separate merged document.

Does it upload documents?

No ProTools upload is required. Merging is performed locally with PDF-Lib.
